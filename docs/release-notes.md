# Clarity v1.0.0

Clarity 1.0 — the first official release, now on **macOS and Windows**.

## Highlights

- **Windows support** — signed installer, SmartScreen-clean, with the same
  auto-updater as macOS. Both platforms ship from every release.
- **More than videos** — Clarity ingests local videos, Loom and YouTube
  links, and **GitHub repositories**. Repos become activity trackers with
  browsable commits and AI change digests.
- **Ask your library** — chat across every summarized source at once, with
  answers that cite (and link to) their sources.
- **Per-source chat** — clickable timestamps for videos, code-aware
  research for repos.
- **Learning diagrams & highlights** — AI-generated conceptual diagrams
  and key-moment screenshots from your sessions.
- **Local-first** — everything is stored on your machine; media goes to
  Gemini only when you ask for a summary.

## Changed in this build

- UI copy updated to reflect all source types (videos, links, repos).
- Signed and notarized macOS build; DigiCert EV-signed Windows build —
  both produced by the new unified release pipeline.
